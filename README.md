# wavecarried

## Description

Wavecarried is an endless physical game inspired by Geometry Dash that features a wave from the game "moving" along an empty background. The main input for the game is a keyboard key, which when held. moves the wave up and when let go, moves the wave down. 

The background has two borders at the top and bottom, and once the wave touches either, the game stops and points (you get 1 point per second survived) are reset. However, the wave constantly varies its speed at which it goes up and down, making the player have to react before the speed throws them off.

The goal of the game is to gain the most points before your hand tires out and/or the wave gets too fast.
